# GitHub Portfolio Setup Guide

## 1. Create the profile repository

Create a new public repository named exactly `aurelliaazhnindy`. GitHub will display its `README.md` on your profile because the repository name matches your username.

## 2. Upload this package

Upload `README.md` and the `portfolio` folder to that repository. Replace the LinkedIn and email placeholders before publishing.

## 3. Create and pin project repositories

For the strongest recruiter experience, later create separate repositories for:

1. `field-operations-control-layer`
2. `msme-business-health-diagnostic`
3. `crm-capability-mapping`
4. `investment-banking-learning-platform`

Each repository should include a README, sanitized screenshots or diagrams, methodology, data dictionary, and a clear confidentiality note. Do not upload employer files, raw business data, customer information, credentials, or proprietary code.

## 4. Profile settings

Suggested bio: `Business Analyst | Strategy, Operations, Investment Research | Power BI, SQL & KPI Design`

Suggested location: `Indonesia · Remote`

Add LinkedIn and a professional email under profile links.

## 5. Pin repositories

Pin the profile repository plus the three strongest case-study repositories. Lead with the work most relevant to the roles you are applying for.
